# Proposal: an internal metrics dashboard for the data team

**Proposal:** build a web dashboard that shows the data team's twelve weekly metrics, with filters, charts and a login. Estimated
effort: **6 engineer-weeks** (one engineer for six weeks), then maintenance.

## Why
Dashboards are the modern way to look at metrics, and the current spreadsheet looks dated.

## Scope
Twelve metrics, role-based login, date filters, export to PDF, dark mode.

## Risks
The schedule could slip if the metric definitions change.
