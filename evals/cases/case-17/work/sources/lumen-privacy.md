# Lumen API: data retention (vendor page, retrieved 5 October 2026)

**Retention.** Inputs and outputs sent to the Lumen API are retained for 30 days for abuse monitoring and are then deleted.
Zero data retention (ZDR) is available only to accounts on an enterprise agreement that includes the signed ZDR addendum.

**Training.** Inputs and outputs are not used to train Lumen models on any plan.
