# tracklabs

Transcribes audio to text and chapters. Last release 2026-09-26.

License: Server Side Public License v1 (SSPL). Offering the software as a hosted service requires releasing your whole service stack under the SSPL.
Telemetry: anonymous usage reports and the audio file's duration and language are sent to the project's servers unless you set `TRACKLABS_TELEMETRY=off`.
