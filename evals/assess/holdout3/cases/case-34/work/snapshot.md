# signup-end

A Hugo shortcode: place `{{< signup-end url="..." >}}` at the end of a page and it renders a box with a short pitch and a button that links to the form URL you give it (a Mailchimp form, for example).
Plain HTML and CSS; no scripts, no tracking, no cookies, no dependencies. Install by copying the shortcode file into your site's layouts from the release commit
