# interview-template

A Reaper project template for a two-person interview recorded on separate tracks: two voice tracks with a gentle high-pass and de-esser already inserted, a music-and-effects track,
a stereo bus with a loudness meter set to -16 LUFS, and an empty markers track for notes. It contains no plugins other than Reaper's own and no scripts; it is one plain text .RPP file you can read.
Install by copying the file into Reaper's ProjectTemplates folder from the release commit `a40e7c19d2b86f35e1c0a9748d3b5f62c1e8097b` after reading it. License: MIT. Last release v1.1.0 (2026-09-21).
