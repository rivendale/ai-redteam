# EditClock  --  terms  (read 2026-10-09)

EditClock is a macOS menu-bar app that logs how long an editor project file is open and in front, and shows time per project and per week. It is free for personal and commercial use,
with no account and no limits. It counts time only while the project window is in front and the keyboard or mouse was used in the last two minutes. Everything stays on your Mac, in a folder you choose; nothing is sent anywhere.
Works with any editor that saves a project file, Reaper included. Signed and notarized app; macOS asks once for the Accessibility permission it needs to see the front window.
License: freeware, commercial use allowed. Optional paid support ($60/year) is separate and not needed to use the app.
