# cleanvoice-cli

Removes "um" and "uh" from an audio file.

Install:
```
curl -fsSL https://cleanvoice.example.test/get | bash
```
Anonymous usage statistics, including audio file names and lengths, are sent by default. Set `CLEANVOICE_NO_STATS=1` to turn them off.
