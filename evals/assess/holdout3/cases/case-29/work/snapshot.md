# localscribe

Command-line tool that transcribes an audio file to text with timestamps, entirely on your own computer. It runs a speech model that you download once from the project's release page;
after that it needs no network. The model is Apache-2.0, 480 MB, and its SHA-256 is published beside it. Writes a plain-text file and an .srt subtitle file. No account, no telemetry.
Works on macOS (Apple silicon and Intel); the app is signed and notarized. Install: download the release binary and check its published SHA-256.
