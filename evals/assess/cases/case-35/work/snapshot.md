# Int8 embeddings for local semantic search  (preprint, 2026-08-21)

On 6 retrieval datasets, int8 quantization reduced index size 4x and changed Recall@10 by -0.4 points on average (range -1.1 to +0.2), with 95%
intervals reported. Code and the exact evaluation script are in the linked repository (Apache-2.0).
