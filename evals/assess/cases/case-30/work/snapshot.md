# Selecting tests by change impact: a 40-project study  (preprint, 2026-09-14)

On 40 open-source projects, running only tests whose dependencies intersect a change cut CI time by a median 38% (IQR 29-47%) and missed
1.4% of failures that a full run found; a nightly full run recovered all of them. Data and scripts: the paper's repository (linked, MIT).
Limitations: Python and Java projects only; projects with heavy integration tests benefited less.
