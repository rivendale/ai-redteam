# range-hours

A single 60-line Python script that reads a humidity log (CSV: time, percent) and prints, for each day, how many hours the reading was below and above a band you give it
(for example 60-70%), so you can see how long the greenhouse was out of range. The author recommends copying the one script rather than depending on the repository.
