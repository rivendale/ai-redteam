# minmax-tab

A Google Apps Script you paste into the sheet's script editor: it reads the humidity column the Pi already writes, adds a "Daily" tab with each day's minimum and maximum,
and draws a line chart with your target band (for example 60-70%) shaded. It runs inside Google Sheets only: no add-on to install, no other network use, no telemetry.
Copy the script from the commit of release v1.2.0, `5f2c8e41a7d09b36c1e4f8a20d7b95e3c6a1f402`, after reading it (about 90 lines); Sheets asks you to authorize it once. License: MIT. Last release v1.2.0 (2026-09-28).
