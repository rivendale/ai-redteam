# cart-nudge

A Shopify theme section for product and collection pages (it cannot be added to the cart or checkout pages): it shows a banner "You left something behind" with a link back to the cart
whenever the cart is not empty, which reminds shoppers who are still browsing. Klaviyo's cart flow, by contrast, emails shoppers who have already left the site. Pure Liquid and CSS (it reads `cart.item_count`); no scripts, no tracking, no dependencies. Install by copying the section file into your theme from the release commit
`c81a4e7f2b95d03a6e1c4f8b7a20d95e3c6b1f48` after reading it. License: MIT. Last release v1.1.0 (2026-09-14).
