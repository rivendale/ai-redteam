# newsletter-rows

Reads a CSV exported from a Google Sheet (name, price, photo URL, link) and prints the HTML for a row of product cards that you paste into an email's HTML block in
Klaviyo or any other email tool. (Klaviyo's own product block reads only from the store catalogue, not from a sheet.) Standard library only; it reads a file and prints to the terminal, no network, no telemetry. Runs on macOS and Linux.
Install: copy the one script, or `pip install newsletter-rows==0.6.2`. License: Apache-2.0. Last release 2026-09-21.
