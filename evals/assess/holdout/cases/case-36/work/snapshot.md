# lfs-lockbot

A small command-line helper for Git LFS file locking: before you open a scene or prefab it tells you who holds the lock, and offers to lock it for you.
It talks only to the Git remote you already use. No telemetry. One Go binary; install it with `go install github.com/example-org/lfs-lockbot@v0.8.2` (Go module versions are fixed by the public checksum database).
