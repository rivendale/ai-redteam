# unity-build-cache-plugin

A Jenkins plugin that adds a "Restore Unity Library cache" and a "Save Unity Library cache" step, keyed on the project's package manifest and Unity version.
The cache lives on the Jenkins agent's disk; nothing leaves the machine. Works with Jenkins 2.440+ on macOS and Windows agents.
Install from the Jenkins plugin manager (signed release). License: Apache-2.0. Last release 2026-09-29.
