# unitykit

Handy commands for Unity projects (clean caches, bump versions, list unused assets).

Install:
```
curl -sSL https://raw.githubusercontent.com/example-org/unitykit/main/install.sh | sh
```
Anonymous usage statistics are collected by default. To turn them off set `UNITYKIT_TELEMETRY=0`.
