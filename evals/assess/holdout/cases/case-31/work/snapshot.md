# Placeholder-safe machine translation for game strings  (preprint, 2026-09-26)

On 4 game string sets in 5 languages, a placeholder-protecting step reduced broken placeholders (such as {0} or %s) in machine output from 6.1% to 0.4% of strings
(95% interval for the reduction: 5.1 to 6.3 points). Translation quality scores were unchanged within the interval. Code, strings and the evaluation script are in the
linked repository (Apache-2.0). Limitation: five languages only; right-to-left languages were not tested.
