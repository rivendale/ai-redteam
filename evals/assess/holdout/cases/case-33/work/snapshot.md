# ILBuildTimer  --  terms  (read 2026-10-08)

ILBuildTimer is a Unity editor tool that prints how long each assembly takes in an IL2CPP Android build and writes the times to a CSV, so you can see where the
minutes go. It is free for commercial and personal use. No account, no card, no usage limits. It works with Unity 6 on macOS and Windows, can run in batch mode so a Jenkins build can use it, and sends nothing anywhere.
License: freeware, commercial use allowed. Optional paid support ($200/year) is separate and not needed to use the tool.
