# unity-bundle-hash

A Unity editor package that skips rebuilding Addressables bundles whose inputs have not changed, using a content hash stored next to each bundle.
Pure C#, no dependencies, no network access, no telemetry. Works with Unity 6 and Jenkins (it is a build step, not a service).
Install from the Package Manager with the git URL pinned to a commit: `https://github.com/example-org/unity-bundle-hash.git#c4e81f0a92d7b35e6a1f8d04b9c27e5a3f61d8b2` (release v2.3.1).
