## What it shows
- The harder cases separate the search tools sharply: grep fell from 26/37 on the clean set to 8/20 here, and findall from 18/37 to 7/20.
  grep only held the chain case (the SUPERSEDED lines sit beside their values); findall only held the long log (one file holds both
  values, and it returns it).
- The model seat did not miss. It used Grep 99 times, Read 96 and Glob 56 over 30 runs, so it found the line past 2,000 by search
  rather than by reading the file top to bottom, and it followed markers across files.

## Limits
